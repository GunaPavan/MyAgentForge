Security isn't an afterthought.

When you're orchestrating LLM-generated code, security has to be baked in from the first commit. Every layer was designed assuming hostile input.

  • BYOK architecture — keys held in browser localStorage only, never transmitted to a database
  • Strict CSP with no unsafe-inline, Subresource Integrity on all CDN assets
  • Sandboxed code execution — POSIX setrlimit on CPU, RAM, file size, PIDs
  • Path-traversal stripping in all file ingest and ZIP download paths
  • Key-redacting log filter — patterns matching sk-, csk-, gsk_, Bearer auto-masked
  • Rate limiting on mutation endpoints via slowapi
  • Zero CVEs across all pinned dependencies (pip-audit on every CI run)

Frequently asked questions.

How do I use this without giving you my API key?

You don't have to. When you open the app, click the gear icon and paste your key — it's stored in your browser's localStorage and only ever leaves your machine inside the encrypted WebSocket frame to our server. The server uses it for that one request and then drops it. There's no database to store it in, by design.

Which LLM providers are supported?

Anything OpenAI-compatible. The settings modal includes one-click configs for Cerebras, Groq, Google Gemini, OpenRouter, Mistral, Together AI, SambaNova, DeepSeek, OpenAI, and local Ollama. If your provider speaks the OpenAI Chat Completions protocol, it works.

Is the code execution actually safe?

The Tester runs LLM-generated code in a subprocess with strict POSIX resource limits: 10s CPU cap, 256MB RAM cap, 10MB file size cap, max 8 processes. The working directory is a disposable tmp dir. Output is truncated to 4KB. On systems with Docker available, it auto-upgrades to a fully isolated container with --network none --read-only.

Can I self-host?

Yes. The whole app is a single FastAPI server packaged in a multi-stage Dockerfile. Clone the repo, docker build && docker run -p 7860:7860, and you're up. Works on Fly.io, Railway, Render, Google Cloud Run, AWS Fargate, or your own VPS.

Will my project history persist?

Yes — in your browser. All projects live in IndexedDB, scoped to this origin. They survive page refreshes, browser restarts, and computer restarts. They're wiped only when you clear browser data, use Incognito, or hit the "Clear all" button.

Is this a portfolio project?

It started that way. It's now a real tool people use — 48 automated tests, full CI, security headers, rate limiting, zero CVEs in dependencies, deployed live on Hugging Face Spaces. Code is MIT licensed; contributions welcome.
